# Exemplo Básico em Java

Projeto simples em Java para demonstrar o uso de variáveis e impressão de dados no console.

## 🛠 Tecnologias
- Java

## 📌 O que o programa faz
- Declara variáveis do tipo:
  - String
  - int
  - double
  - boolean
- Exibe os valores no console utilizando `System.out.println`

## ▶️ Como executar
1. Abra o projeto em uma IDE (IntelliJ, Eclipse, VS Code, etc.)
2. Execute a classe `Main`
3. Veja as informações exibidas no console

## 📚 Objetivo
Praticar conceitos básicos da linguagem Java, como:
- Tipos de dados
- Declaração de variáveis
- Saída de dados no con
